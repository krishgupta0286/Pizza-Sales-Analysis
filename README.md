# Pizza Sales Analysis

## Project Overview

This project focuses on analyzing pizza sales data using SQL and Power BI to understand sales performance and identify key business insights.

The analysis covers revenue, orders, pizzas sold, average order value, pizza categories, pizza sizes, daily and monthly order trends, and top-performing pizzas.

## Tools & Technologies

- SQL
- SQL Server
- Power BI

## Dataset

- Domain: Pizza Sales
- Table: `pizza_sales`

The dataset contains pizza order and sales information such as order date, order ID, pizza name, pizza category, pizza size, quantity, and total price.

## SQL Analysis

SQL was used to analyze pizza sales performance and answer business-related questions.

The analysis included:

- Total revenue
- Average order value
- Total pizzas sold
- Total orders
- Average pizzas per order
- Daily order trends
- Monthly order trends
- Sales by pizza category
- Sales by pizza size
- Total pizzas sold by category
- Top 5 pizzas by revenue
- Bottom 5 pizzas by revenue
- Top 5 pizzas by quantity
- Bottom 5 pizzas by quantity
- Top 5 pizzas by total orders
- Bottom 5 pizzas by total orders

## Power BI Dashboard

A Power BI dashboard was created to visualize key sales KPIs and business trends.

The dashboard includes:

- Total Revenue

- Average Pizzas per Order
- Daily Order Trend
- Monthly Order Trend
- Sales by Pizza Category
- Sales by Pizza Size
- Total Pizzas Sold by Category
- Top 5 Pizzas by Revenue

## Key Insights

- Friday recorded the highest number of orders at approximately 3.5K.
- July recorded the highest monthly orders with 1,935 orders.
- Classic pizzas generated the highest share of sales at 26.91%.
- Large pizzas contributed the highest share of sales at 45.89%.
- Thai Chicken Pizza generated the highest revenue among the Top 5 pizzas at approximately 43.43K.
